## 🚀 How to Use

### Single Certificate (5 minutes)
1. Open `index.html` in your browser
2. Enter participant details
3. Upload logo/signature (optional)
4. Click Download PNG or PDF

### Batch Certificates (2-5 minutes)
1. Prepare Excel file (.xlsx) with:
   - Column A: Name
   - Column B: Event
   - Column C: Date
   - Column D: Issuer
2. Upload Excel file in "Batch Certificate" section
3. Click "Process & Download All"
4. Wait for progress bar to complete
5. Download ZIP file with all certificates
